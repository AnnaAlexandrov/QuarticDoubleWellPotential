# Асимметричная двойная потенциальная яма: метод Нумерова с matching technique

Проект решает стационарное одномерное уравнение Шрёдингера в безразмерных единицах

\[
-\frac12\frac{d^2\psi}{dx^2}+V(x)\psi(x)=E\psi(x),
\qquad \hbar=m=1,
\]

для потенциала

\[
V(x)=V_0(x^2-1)^2+\alpha x.
\]

При `alpha = 0` яма симметрична, её минимумы расположены вблизи `x = ±1`, а высота центрального барьера равна `V0`. Ненулевой параметр `alpha` наклоняет потенциал и снимает вырождение локальных минимумов.

## Что реализовано

- равномерная пространственная сетка и граничные условия Дирихле;
- шестого порядка рекуррентная формула Нумерова;
- независимое интегрирование слева и справа;
- автоматический выбор точки сшивки около центрального барьера;
- сшивка по вронскиану, не имеющая сингулярности при узле волновой функции в точке сшивки;
- поиск собственных энергий как нулей mismatch-функции;
- устойчивое предварительное разбиение энергетической оси с помощью последовательности Штурма для вспомогательного трёхдиагонального гамильтониана;
- нормировка собственных функций;
- графики потенциала, уровней и волновых функций;
- проверка сходимости по шагу сетки и размеру расчётной области;
- тест на гармоническом осцилляторе с известным точным спектром.

Последовательность Штурма используется **только для грубого выделения отдельного интервала для каждого уровня**. Финальное значение энергии всегда находится из условия обращения в ноль вронскиана двух решений, построенных методом Нумерова.

## Как читать код

Все функции, классы и нетривиальные участки алгоритма снабжены русскоязычными docstring-комментариями и пояснениями непосредственно в коде. Рекомендуемый порядок чтения:

1. `potentials.py` — как задаётся потенциал в виде Python callable;
2. `numerov.py` — сетка, рекурсия Нумерова и вычисление производных;
3. `solver.py` — построение двух ветвей, вронскиан, поиск корней и нормировка;
4. `analysis.py` — проверки сходимости;
5. `cli.py` — как все части соединяются в запускаемую программу;
6. `tests/test_solver.py` — какие свойства решения проверяются автоматически.

Комментарии намеренно объясняют не только *что* делает строка, но и *зачем* соответствующий шаг нужен физически или численно.

## Быстрый запуск

```bash
python -m double_well_solver \
  --v0 5 \
  --alpha 0.25 \
  --xmax 4 \
  --points 2001 \
  --states 6 \
  --energy-max 25 \
  --output results \
  --convergence
```

То же самое после установки консольной команды:

```bash
double-well --v0 5 --alpha 0.25 --states 6 --convergence
```

Основные параметры:

- `--v0` — масштаб высоты барьера;
- `--alpha` — линейная асимметрия;
- `--xmax` — расчётная область `[-xmax, xmax]`;
- `--points` — число узлов сетки;
- `--match-x` — ручной выбор точки сшивки; без него она выбирается автоматически;
- `--energy-min`, `--energy-max` — энергетическое окно;
- `--states` — число требуемых уровней;
- `--convergence` — выполнить исследования сходимости.

## Выходные файлы

В каталоге результатов создаются:

- `spectrum.csv` — номер уровня, энергия и остаточная mismatch-функция;
- `wavefunctions.csv` — сетка, потенциал, собственные функции и плотности вероятности;
- `eigenstates.png` — потенциал и волновые функции, сдвинутые на соответствующие энергии;
- `mismatch.png` — нормированный вронскиан как функция энергии;
- `grid_convergence.csv` — изменение энергий при уменьшении `dx`;
- `domain_convergence.csv` — изменение энергий при удалении границ.

## Использование произвольного потенциала

Численный алгоритм не связан с формулой двойной ямы. Ему можно передать любой вызываемый объект Python:

```python
import numpy as np

from double_well_solver import MatchedNumerovSolver, UniformGrid


def potential(x: np.ndarray) -> np.ndarray:
    return 0.5 * x**2 + 0.02 * x**4


solver = MatchedNumerovSolver(
    potential,
    UniformGrid(-7.0, 7.0, 2801),
    match_x=0.0,
)

states = solver.solve(
    energy_min=0.0,
    energy_max=10.0,
    n_states=5,
)

for state in states:
    print(state.index, state.energy)
```

## Численные замечания

1. Границы должны лежать глубоко в классически запрещённой области: `V(x_min), V(x_max) >> E_max`.
2. Нельзя судить о корректности границы только по `psi(x_min)=psi(x_max)=0`, поскольку это условие задано искусственно. Поэтому программа дополнительно выводит плотность вероятности немного внутри границ и разность `V_boundary - E_highest`.
3. Уменьшение `dx` и увеличение области должны менять интересующие энергии меньше требуемой точности.
4. Для почти вырожденных туннельных дублетов грубый глобальный energy scan может пропустить два близких нуля. Поэтому проект сначала отделяет уровни последовательностью Штурма, а затем уточняет каждый уровень через Numerov matching.
