# Численное решение задачи об асимметричной двойной яме

## 1. Постановка задачи

Рассматривается частица массы `m = 1` в одномерном потенциале

\[
V(x)=V_0(x^2-1)^2+\alpha x,
\]

в единицах `ℏ = 1`. Стационарное уравнение Шрёдингера имеет вид

\[
-\frac12\psi''(x)+V(x)\psi(x)=E\psi(x).
\]

После умножения на `−2` оно приводится к форме

\[
\psi''(x)+k(x;E)\psi(x)=0,
\qquad
k(x;E)=2[E-V(x)].
\]

Потенциал растёт как `x^4`, поэтому связанные состояния экспоненциально затухают при больших `|x|`. На конечной области `[x_min,x_max]` используются условия

\[
\psi(x_{\min})=\psi(x_{\max})=0.
\]

Границы следует выбирать достаточно далеко, чтобы они находились в классически запрещённой области для всех вычисляемых уровней.

## 2. Формула Нумерова

На равномерной сетке `x_n=x_min+nΔx` применяется рекуррентное соотношение

\[
\left(1+\frac{\Delta x^2}{12}k_{n+1}\right)\psi_{n+1}
=2\left(1-\frac{5\Delta x^2}{12}k_n\right)\psi_n
-\left(1+\frac{\Delta x^2}{12}k_{n-1}\right)\psi_{n-1}.
\]

Для левой ветви задаются

\[
\psi_0=0,\qquad \psi_1=\varepsilon,
\]

а для правой ветви

\[
\psi_{N-1}=0,\qquad \psi_{N-2}=\varepsilon.
\]

Значение `ε` произвольно, поскольку линейное однородное уравнение определяет собственную функцию только с точностью до общего множителя. В программе используется `ε=10^{-12}`.

## 3. Почему используется сшивка

Прямое интегрирование через всю область может быть неустойчивым: в классически запрещённой области вместе с физически затухающим решением существует экспоненциально растущее решение. Малые ошибки округления способны возбудить растущую компоненту.

Поэтому решение строится двумя частями:

- `ψ_L(x)` интегрируется от левой границы к точке `x_m`;
- `ψ_R(x)` интегрируется от правой границы к той же точке.

По умолчанию `x_m` выбирается как максимум потенциала между двумя наиболее глубокими локальными минимумами, то есть около центрального барьера. Пользователь может задать `match_x` вручную.

## 4. Mismatch-функция

Прямое сравнение логарифмических производных

\[
\frac{\psi_L'}{\psi_L}-\frac{\psi_R'}{\psi_R}
\]

неудобно, если в точке сшивки находится узел и `ψ(x_m)=0`. Поэтому используется вронскиан

\[
W(E)=\psi_L'(x_m)\psi_R(x_m)
-\psi_R'(x_m)\psi_L(x_m).
\]

Две ветви являются линейно зависимыми, а значит образуют одну собственную функцию, тогда и только тогда, когда `W(E)=0`.

Для улучшения масштаба вычисляется нормированная функция

\[
\Delta(E)=
\frac{W(E)}
{\sqrt{\psi_L^2+\psi_L'^2}\,
 \sqrt{\psi_R^2+\psi_R'^2}}.
\]

Нормировка не меняет положения нулей, но ограничивает величину mismatch-функции и делает поиск корней устойчивее.

Производные в точке сшивки рассчитываются односторонними пятиузловыми формулами четвёртого порядка.

## 5. Выделение отдельных уровней

Для обычных уровней достаточно просканировать `Δ(E)` на равномерной энергетической сетке и искать перемены знака. Однако в высокой симметричной двойной яме туннельное расщепление первых двух уровней может быть экспоненциально малым. Тогда два нуля способны оказаться внутри одного шага сканирования, и знаки на концах шага совпадут.

Чтобы не пропускать такие дублеты, в проекте используется двухэтапная процедура:

1. На той же пространственной сетке строится вспомогательный трёхдиагональный гамильтониан второго порядка.
2. Последовательность Штурма определяет, сколько его собственных значений лежит ниже данной энергии.
3. Бисекцией находятся приближённые энергии и отдельный интервал для каждого уровня.
4. В каждом интервале ищется ноль именно Numerov mismatch-функции.

Следовательно, вспомогательная конечно-разностная задача отвечает только за надёжное bracketing. Финальные энергии определяются требуемой схемой Нумерова и matching technique.

## 6. Сборка и нормировка волновой функции

При найденной энергии правая ветвь умножается на коэффициент `λ`. Он выбирается методом наименьших квадратов в локальном пространстве `(ψ,ψ')`:

\[
\lambda=
\frac{\psi_L\psi_R+\psi_L'\psi_R'}
{\psi_R^2+\psi_R'^2}.
\]

Такая формула остаётся корректной и при `ψ(x_m)=0`. После объединения ветвей функция нормируется условием

\[
\int_{x_{\min}}^{x_{\max}}|\psi_n(x)|^2dx=1.
\]

## 7. Пример расчёта

Для параметров

```text
V0 = 5
alpha = 0.25
x in [-4,4]
N = 2001
```

получены первые шесть уровней:

| n | E_n |
|---:|---:|
| 0 | 2.571625004800 |
| 1 | 3.127656431641 |
| 2 | 6.641383771376 |
| 3 | 9.310522066985 |
| 4 | 13.008392127840 |
| 5 | 17.132303576883 |

Остаточные значения нормированного вронскиана для этих корней лежат примерно в диапазоне `10⁻¹³–10⁻¹⁰`.

## 8. Проверка сходимости

Для того же примера изменение числа узлов дало:

| N | Δx | E_0 | E_1 | E_5 |
|---:|---:|---:|---:|---:|
| 1000 | 0.008008 | 2.571625000937 | 3.127656428294 | 17.132303396710 |
| 2001 | 0.004000 | 2.571625004800 | 3.127656431641 | 17.132303576883 |
| 3003 | 0.002665 | 2.571625004963 | 3.127656431824 | 17.132303587027 |

При увеличении полуширины области от `3.4` до `4.6` при сохранении `Δx=0.004` показанные энергии не изменились в напечатанных разрядах. Это означает, что для данного энергетического диапазона границы уже находятся достаточно далеко.

## 9. Верификация

Автоматический тест решает задачу гармонического осциллятора

\[
V(x)=\frac{x^2}{2},
\]

для которого точный спектр равен

\[
E_n=n+\frac12.
\]

Первые четыре численных уровня совпадают с точными с абсолютной ошибкой менее `2×10⁻⁶` на используемой тестовой сетке.

## 10. Вывод

Реализация удовлетворяет требованиям задания:

- потенциал передаётся как независимый Python callable;
- используется рекуррентная схема Нумерова;
- решение интегрируется от обеих границ;
- ветви сшиваются в промежуточной точке;
- собственные энергии находятся как корни mismatch-функции;
- корректность контролируется изменением `Δx` и размера области;
- предусмотрен устойчивый режим для почти вырожденных туннельных уровней.
