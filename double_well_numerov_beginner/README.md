# Double-well potential: beginner version

Это намеренно простая учебная реализация метода Нумерова для потенциала

\[
V(x)=V_0(x^2-1)^2+\alpha x.
\]

Проект переписан так, будто его делал студент, недавно начавший программировать:

- нет классов;
- нет пакета и сложной структуры каталогов;
- нет `argparse`, конфигурационных файлов и установки через `pip -e`;
- нет метода Штурма, матричной диагонализации и адаптивного поиска;
- энергия просматривается обычным циклом с постоянным шагом;
- корень уточняется простым методом бисекции;
- пространственная сетка создаётся одной строкой `numpy.linspace`;
- параметры меняются непосредственно в начале `main.py`.

## Структура

- `main.py` — задаёт параметры, запускает расчёт, сохраняет таблицы и рисунок;
- `numerov_functions.py` — потенциал, метод Нумерова, невязка, поиск энергий и сшивка;
- `convergence_check.py` — простая проверка зависимости от границ и шага сетки;
- `results/` — пример результатов.

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

После запуска в папке `results` появятся:

- `energies.csv`;
- `wavefunctions.csv`;
- `eigenstates.png`.

Проверка устойчивости результата:

```bash
python convergence_check.py
```

## Как ищется энергия

В `main.py` задаются три числа:

```python
energy_min = 0.0
energy_max = 20.0
energy_step = 0.05
```

Программа последовательно проверяет энергии

```text
0.00, 0.05, 0.10, 0.15, ...
```

На каждой энергии вычисляется вронскиан левой и правой частей решения. Когда
его знак меняется, программа считает, что между двумя соседними энергиями есть
корень, и уточняет его методом половинного деления.

Это очень простой способ. Он может пропустить два уровня, если они лежат ближе
друг к другу, чем `energy_step`. В таком случае нужно вручную уменьшить
`energy_step`.

## Точка сшивки

В примере используется

```python
match_x = 0.2
```

Точка находится около центрального барьера. Значение не выбирается программой
автоматически. Его можно поменять вручную и проверить, что найденные энергии
почти не изменились.

## Границы области

На концах области задаётся

\[
\psi(x_{min})=\psi(x_{max})=0.
\]

Поэтому `x_min` и `x_max` должны находиться достаточно далеко внутри
классически запрещённой области. В `convergence_check.py` расчёт повторяется
для нескольких размеров области и нескольких шагов сетки.
