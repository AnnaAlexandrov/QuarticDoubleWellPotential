# Численный метод: функциональная версия

## 1. Уравнение

Используются единицы \(\hbar=m=1\):

\[
-\frac12\frac{d^2\psi}{dx^2}+V(x)\psi=E\psi,
\qquad
V(x)=V_0(x^2-1)^2+\alpha x.
\]

После преобразования:

\[
\psi''+k(x;E)\psi=0,
\qquad
k(x;E)=2(E-V(x)).
\]

## 2. Функциональная организация

Численная задача не хранится внутри экземпляра решателя. Функция
`prepare_problem` один раз вычисляет сетку, потенциал и точку сшивки и
возвращает словарь. Каждая последующая функция получает этот словарь явно.

Такой интерфейс делает зависимости заметными непосредственно в сигнатурах:

```python
mismatch(problem, energy)
find_eigenvalues(problem, energy_min, energy_max, ...)
build_eigenstate(problem, energy)
```

## 3. Рекурсия Нумерова

Для равномерного шага \(h\):

\[
\left(1+\frac{h^2k_{n+1}}{12}\right)\psi_{n+1}
=2\left(1-\frac{5h^2k_n}{12}\right)\psi_n
-\left(1+\frac{h^2k_{n-1}}{12}\right)\psi_{n-1}.
\]

Функции `integrate_from_left` и `integrate_from_right` реализуют одну и ту же
формулу в противоположных направлениях. Рабочие массивы изменяются только
локально внутри этих функций и не образуют глобального состояния.

## 4. Сшивка

Левая и правая ветви строятся до общего узла \(x_m\). Условие собственного
значения задаётся нулём вронскиана:

\[
W(E)=\psi_L'(x_m)\psi_R(x_m)-
      \psi_R'(x_m)\psi_L(x_m)=0.
\]

В коде используется нормированный вариант, не зависящий от произвольных
начальных масштабов ветвей.

## 5. Поиск уровней

Сначала конечно-разностная последовательность Штурма оценивает число уровней
ниже пробной энергии. Она разделяет близкие уровни на отдельные интервалы.
После этого каждый физический корень уточняется бисекцией по Numerov mismatch.

## 6. Волновая функция

Правая ветвь масштабируется методом наименьших квадратов в плоскости
\((\psi,\psi')\), после чего обе части объединяются и нормируются:

\[
\int |\psi_n(x)|^2\,dx=1.
\]

Результат возвращается как словарь, а не как экземпляр пользовательского типа.

## 7. Контроль точности

Проект проверяет:

- сходимость по числу узлов;
- сходимость по размеру области;
- малость плотности около границ;
- положительный запас \(V(x_{\min/\max})-E_{\max}\);
- точный спектр гармонического осциллятора в тестах.
